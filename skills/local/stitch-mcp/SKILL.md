# Stitch MCP

Use this skill when the user wants to create or iterate UI designs with Stitch MCP.

## Workflow

1. Clarify the target device and fidelity:
   - mobile, desktop, tablet, watch
   - wireframe, high-fidelity mock, design system, or component
2. Turn vague requests into a concrete design prompt with layout, content, tone, constraints, and brand direction.
3. Use Stitch MCP tools when available; keep IDs exactly as returned by the tool.
4. After generation, inspect the result and iterate on the most important mismatch first.

## Rules

- Preserve project/product constraints over generic design trends.
- Ask before generating radically different visual directions.
- Record reusable tokens (colors, type, spacing, radius) when creating a design system.
